# UI kit — App del veterinario (móvil)

Paridad funcional total con la web, en 372px. Reutiliza `../clinica-web/data.js`.

`VetScreens.jsx` contiene: `VetAgenda`, `VetPatients`, `VetPatientDetail`, `VetQuickForm`, `VetProfile`.

Decisiones propias del móvil: alturas táctiles de 52px (`size="touch"`), CTA principal sticky al pie sobre degradado de protección, y la ficha abre directamente en el bloque de datos críticos.
