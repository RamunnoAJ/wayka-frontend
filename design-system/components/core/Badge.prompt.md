Etiqueta de estado sobria: fondo neutro unico, el significado lo lleva un punto (o icono) de color apagado. El texto solo sube de contraste en danger.

```jsx
<Badge tone="danger" icon="triangle-alert">Alergia</Badge>
```

tone: neutral/primary/success/warning/danger/info ('brand' y 'accent' deprecados → primary) · size sm/md · sin fondos de color.
